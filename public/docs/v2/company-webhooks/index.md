**Вебхук компании** — HTTPS-эндпоинт, который вы регистрируете для компании. Когда что-то происходит — новое сообщение, обновление диалога, изменение канала — Pact.im отправляет `POST` на этот URL с данными события.

У каждой компании может быть несколько вебхуков (до пяти). Новые вебхуки создаются неактивными; включайте их, когда URL готов. Форматы данных событий и правила доставки описаны в разделе [События](/v2/webhooks).

С API вебхуков компании вы можете:

- [Получить вебхуки компании](/v2/company-webhooks/get-company-webhooks)
- [Создать вебхук](/v2/company-webhooks/create-webhook)
- [Обновить вебхук](/v2/company-webhooks/update-webhook)
- [Удалить вебхук](/v2/company-webhooks/delete-webhook)

## Объект webhook

### Пример

```json
{
  "webhook": {
    "id": 1,
    "url": "https://example.com/webhook",
    "active": true
  }
}
```

### Описание

Параметр | Тип | Описание
--------- | ---- | -----------
id | Integer | ID
url | String | URL вебхука
active | Boolean | Активен ли вебхук
