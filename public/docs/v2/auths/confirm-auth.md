После [создания канала](/v2/auths/create-auth) способ подтверждения подключения определяется провайдером. Об изменениях статуса канала также приходят вебхуки — см. [События каналов](/v2/webhooks/auth-events).

## Аутентификация по QR-коду

Аутентификацию по QR-коду поддерживают:

- `whatsapp`
- `telegram_personal`
- `max`

После создания канала ответ API содержит поле `qr` с изображением QR-кода в кодировке Base64.

Тот же QR-код доставляется в событии вебхука `update`.

Когда срок действия QR-кода истекает, отправляется ещё одно событие вебхука `update` с новым QR-кодом.

## Аутентификация по коду

Аутентификация по коду доступна для:

- `whatsapp`
- `telegram_personal`

Если в запрос [создания канала](/v2/auths/create-auth) передан параметр `phone_number`, вместо аутентификации по QR-коду используется аутентификация по коду.

### WhatsApp

Ответ содержит поле `code`.

Тот же код доставляется через вебхук `update`.

### Telegram Personal

Telegram отправляет код подтверждения непосредственно на устройство пользователя.

Полученный код необходимо передать при [включении канала](/v2/auths/enable-auth):

`PUT/PATCH https://api.pact.im/api/p2/companies/{company_id}/auths/{id}/enable`

Запрос:

```json
{
  "code": "12345"
}
```

## Аутентификация через OAuth

Аутентификацию через OAuth поддерживают:

- `facebook`
- `vkontakte`
- `instagram_business`
- `whatsapp_business`
- `avito`

После создания канала ответ содержит поле `oauth_provider_url`.

Тот же URL доставляется через вебхук `update`.

Пользователю надо открыть URL и пройти подключение у провайдера.

Для всех провайдеров, кроме VKontakte, канал становится активной автоматически после получения обратного вызова OAuth.

### VKontakte

Канал во VKontakte состоит из двух шагов.

#### Шаг 1

Откройте первоначальный `oauth_provider_url` и пройдите канал.

#### Шаг 2

Приходит вебхук `update` со списком всех доступных сообществ.

Каждое сообщество содержит собственный `oauth_provider_url`.

Откройте URL нужного сообщества, чтобы завершить подключение.

Пример:

```json
{
  "pages": [
    {
      "id": 30289,
      "enabled": false,
      "name": "test",
      "external_id": "232630093",
      "oauth_provider_url": "https://oauth.vk.ru/authorize?..."
    }
  ]
}
```
