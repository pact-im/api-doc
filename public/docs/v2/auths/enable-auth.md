Включает существующий канал.

## HTTP Request

`PUT https://api.pact.im/api/p2/companies/<COMPANY_ID>/auths/<AUTH_ID>/enable`

## Параметры URL

Параметр | Описание
--------- | -----------
COMPANY_ID | ID компании
AUTH_ID | ID канала

## Параметры запроса

Параметр | Обязательный | Валидация | Описание
--------- | -------- | ----------- | -----------
private_api_token | да | Должно быть строкой | YOUR_API_TOKEN

## Параметры тела запроса

Параметр | Обязательный | Валидация | Описание
--------- | -------- | ----------- | -----------
code | нет | Должно быть строкой | Требуется только для telegram_personal (аутентификация по коду)
