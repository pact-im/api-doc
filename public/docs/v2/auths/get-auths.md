Возвращает каналы нескольких компаний.

## HTTP Request

`GET https://api.pact.im/api/p2/auths`

## Параметры запроса

Параметр | Обязательный | Валидация | Описание
--------- | -------- | ----------- | -----------
private_api_token | да | Должно быть строкой | YOUR_API_TOKEN
company_ids | да | Должно быть массивом целых чисел | Список ID компаний
page | нет | Должно быть целым числом | Номер страницы
per_page | нет | Должно быть целым числом | Количество записей на странице
