Позволяет удалять сообщения.

На данный момент доступны только следующие провайдеры: <b>whatsapp, telegram_personal, max</b>

## HTTP Request

`DELETE https://api.pact.im/api/p2/conversations/CONVERSATION_ID/messages`

## Параметры тела запроса (JSON)

Параметр | Обязательный | Валидация | Описание
--------- | -------- | ----------- | -----------
message_ids  | да | Должно быть массивом целых чисел | Идентификаторы сообщений, которые нужно удалить. Максимальный размер массива — 100 элементов.
company_id | да | Должно быть целым числом | Идентификатор компании
