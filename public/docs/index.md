[Pact.im](https://pact.im) — это мессенджер-платформа для бизнеса. Она собирает WhatsApp, Telegram, MAX, VK, Avito, Instagram и другие каналы в одном месте, чтобы ваша команда могла продавать, поддерживать клиентов и вести переписку, не переключаясь между приложениями.

Компании используют Pact.im как общий инбокс: с ИИ-ассистентами для ответов и аналитики диалогов, синхронизацией с CRM (amoCRM, Bitrix24 и собственные системы), рассылками и телефонией в WhatsApp. Внутри — та же платформа, доступная через этот API.

Используйте **API Pact.im**, когда нужно связать Pact.im с собственным продуктом, CRM или бэкендом: отправлять и получать сообщения, управлять диалогами, подключать каналы и реагировать на события через вебхуки.

Мы делаем API сфокусированным на том, что действительно нужно командам в продакшене. Если чего-то важного не хватает — [напишите нам](https://pact.im): мы выпускаем методы, которые решают реальные задачи интеграции.

## Начните за несколько минут

1. **Создайте аккаунт** — [зарегистрируйтесь](https://app.pact.im/signup) (Pact.im можно бесплатно попробовать несколько дней).
2. **Скопируйте API-токен** — он находится в [настройках аккаунта](https://app.pact.im/account).
3. **Подключите канал** — WhatsApp, Telegram, Instagram или другого провайдера в [настройках проекта](https://app.pact.im/project_settings).
4. **Направьте вебхуки на свой сервер** — чтобы получать сообщения и обновления диалогов в момент их появления. См. [Вебхуки компании](/v2/company-webhooks) и [События](/v2/webhooks).
5. **Отправьте или получите сообщения** — начните с разделов [Сообщения](/v2/messages) и [Диалоги](/v2/conversations).

> **Warning:** Для всех новых интеграций используйте **API v2**. **API v1** устарел и документируется только для уже существующих интеграций. Если вы всё ещё используете [Каналы](/v1/channels) из v1, воспользуйтесь руководством [Переход с API v1 на API v2 для Каналов](/migrate-channels-to-auths), чтобы перейти на [Каналы](/v2/auths) и [События каналов](/v2/webhooks/auth-events) в v2. Точная дата отключения каналов v1 будет объявлена позднее в этом году; после неё они перестанут работать полностью.

## Как обращаться к API

Обращаться к API Pact.im можно из любого HTTP-клиента: `curl`, Postman или стандартных библиотек вашего языка. В примерах этой документации используется `curl`, чтобы вы могли быстро попробовать запросы прямо из терминала.

Аутентификация, пагинация, лимиты запросов и ошибки описаны в соответствующих разделах в боковом меню.
