Создаёт новый канал (auth) для провайдера мессенджера.

## HTTP Request

`POST https://api.pact.im/api/p2/companies/<COMPANY_ID>/auths`

## Параметры URL

Параметр | Описание
--------- | -----------
COMPANY_ID | ID компании

## Параметры запроса

Параметр | Обязательный | Валидация | Описание
--------- | -------- | ----------- | -----------
private_api_token | да | Должно быть строкой | YOUR_API_TOKEN

## Параметры тела запроса

Параметр | Обязательный | Валидация | Описание
--------- | -------- | ----------- | -----------
provider | да | Должно быть строкой | Название провайдера (например, whatsapp, telegram, vkontakte)
sync_period | нет | Одно из значений: day, week, month | Период синхронизации сообщений (необязательный)

Синхронизация сообщений поддерживается только следующими провайдерами:

- `telegram_personal`
- `whatsapp`
- `max`
- `instagram_business`
- `vkontakte`
- `vkontakte_direct`

## Параметры провайдеров

| Провайдер | Параметры создания | Параметры включения |
|----------|-------------------|-------------------|
| `whatsapp` | `provider`, необязательно `phone_number`, необязательно `sync_period` | Дополнительные параметры не требуются |
| `telegram_personal` | `provider`, необязательно `phone_number`, необязательно `sync_period` | `code` требуется только при аутентификации по коду. Для повторного включения отключённого канала дополнительные параметры не нужны. |
| `max` | `provider`, необязательно `sync_period` | Дополнительные параметры не требуются |
| `telegram` | `provider`, `token` | Дополнительные параметры не требуются |
| `viber` | `provider`, `token` | Дополнительные параметры не требуются |
| `odnoklassniki` | `provider`, `token` | Дополнительные параметры не требуются |
| `max_bot` | `provider`, `token` | Дополнительные параметры не требуются |
| `vkontakte_direct` | `provider`, `token`, необязательно `sync_period` | Дополнительные параметры не требуются |
| `vkontakte` | `provider`, необязательно `sync_period` | Дополнительные параметры не требуются |
| `facebook` | `provider` | Дополнительные параметры не требуются |
| `instagram_business` | `provider`, необязательно `sync_period` | Дополнительные параметры не требуются |
| `whatsapp_business` | `provider` | Дополнительные параметры не требуются |
| `avito` | `provider` | Дополнительные параметры не требуются |
| `custom` | `provider` | необязательно `client_url` |

## Дальнейшие шаги

В зависимости от провайдера перейдите к [подтверждению канала](/v2/auths/confirm-auth) (QR-код, код или OAuth).

Об изменениях каналов также сообщается через вебхуки. См. [События каналов](/v2/webhooks/auth-events).
