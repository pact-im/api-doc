**Вложение** — это файл, сохранённый в Pact.im, который можно отправить в [сообщении](/v2/messages): изображение, документ, аудио, видео и другие медиафайлы.

Сначала загрузите файл, а затем передайте его идентификатор в параметре `attachment_ids` при отправке сообщения. Пока вложение не прикреплено к сообщению, поле `message_id` может быть пустым. Для вложений-изображений дополнительно возвращаются ссылка на превью, соотношение сторон и размеры.

Используйте вложения, когда в диалоге нужно передать не только текст.

- [Загрузить вложение](/v2/attachments/upload-attachment)

## Объект вложения

### Пример

```json
{
  "attachment": {
    "id": 53439177,
    "message_id": null,
    "file_name": "1.jpg",
    "mime_type": "image/jpg",
    "size": 812089,
    "attachment_url": "The path to the file",
    "preview_url": "The path to the file",
    "aspect_ratio": 0.8,
    "data": {
      "width": 1024,
      "height": 1280
    },
    "push_to_talk": null
  }
}
```

### Описание

Параметр | Тип | Описание
--------- | ---- | -----------
id | Integer | Идентификатор
message_id | Integer | Идентификатор сообщения
file_name | String | Исходное имя файла
mime_type | String | MIME-тип (например, `audio/ogg`)
size | Integer | Размер файла в байтах
attachment_url | String | URL файла
preview_url | String | URL превью изображения (если это изображение)
aspect_ratio | Float | Соотношение сторон (если это изображение)
data | Object | Ширина и высота (если это изображение)
push_to_talk | Boolean | Голосовое сообщение или обычный аудиофайл (если это аудио)
