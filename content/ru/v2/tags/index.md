Теги помогают классифицировать диалоги. Сначала создайте тег в общем каталоге, затем назначьте его одному или нескольким диалогам.

Теги принадлежат владельцу аккаунта и доступны во всех его компаниях. Для одного владельца можно создать до 200 тегов, а для одного диалога назначить до 10 тегов.

С API тегов вы можете:

- [Получить каталог тегов](/v2/tags/get-tags)
- [Создать тег](/v2/tags/create-tag)
- [Обновить тег](/v2/tags/update-tag)
- [Удалить тег](/v2/tags/delete-tag)
- [Получить теги диалога](/v2/tags/get-conversation-tags)
- [Назначить тег диалогу](/v2/tags/assign-conversation-tag)
- [Снять тег с диалога](/v2/tags/remove-conversation-tag)

## Объект тега

### Пример

```json
{
  "tag": {
    "id": 42,
    "title": "VIP",
    "color": "purple",
    "position": 1,
    "created_at": "2026-11-19T12:00:00.000Z",
    "updated_at": "2026-11-19T12:00:00.000Z"
  }
}
```

### Описание

Параметр | Тип | Описание
--------- | ---- | -----------
id | Integer | ID тега
title | String | Название тега, до 30 символов. Названия уникальны в каталоге владельца без учёта регистра
color | String | Цвет тега: `red`, `orange`, `yellow`, `green`, `teal`, `blue`, `purple`, `pink` или `gray`
position | Integer | Позиция тега в каталоге владельца
created_at | Time | Время создания
updated_at | Time | Время последнего обновления
