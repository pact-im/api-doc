---
title: "Ошибки"
description: "HTTP-коды ошибок, которые возвращает API Pact"
section: "reference"
---

API Pact использует следующие коды ошибок:

HTTP-статус | Значение
---------- | -------
400 | Bad Request — запрос никуда не годится
401 | Unauthorized — неверный API-ключ
402 | Payment Required — для компании включён платный доступ, нужно оплатить перед запросами к API
403 | Forbidden — этот эндпоинт вам недоступен
404 | Not Found — указанный ресурс не найден
405 | Method Not Allowed — вы обратились неподходящим методом
406 | Not Acceptable — вы запросили формат, отличный от json
410 | Gone — запрошенный ресурс удалён с наших серверов
418 | I'm a teapot — я чайник
429 | Too Many Requests — слишком много запросов! Помедленнее!
500 | Internal Server Error — проблема на нашем сервере. Попробуйте позже.
502 | Bad Gateway — мы временно недоступны из-за техработ. Попробуйте позже.
503 | Service Unavailable — мы временно недоступны из-за техработ. Попробуйте позже.
